# ⚡ DSA-GRIND

### Stop scrolling. Start solving. Get better at DSA.

DSA-GRIND is an interactive platform designed to make Data Structures and Algorithms practice more structured, engaging, and consistent.

Whether you're starting from scratch or preparing for coding interviews, DSA-GRIND helps you track your progress and stay accountable throughout your learning journey.

## ✨ Features

- 📚 **Structured DSA Roadmap** — Learn topics from beginner to advanced levels.
- 🎯 **Curated Problems** — Practice problems organized by topic and difficulty.
- ✅ **Progress Tracking** — Mark problems as solved and monitor your growth.
- 🔥 **Daily Streaks** — Build consistency through daily practice.
- 📊 **Activity Heatmap** — Visualize your coding activity.
- 🔖 **Bookmarks** — Save important problems for later revision.
- 📝 **Personal Notes** — Keep track of concepts and approaches.
- 🔍 **Search & Filters** — Find problems quickly.
- 🎉 **Celebration Effects** — Get a little motivation whenever you solve a problem.
- 💾 **Local Data Storage** — Keep your progress saved in your browser.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- LocalStorage

## 🚀 Getting Started

Follow these steps to run DSA-GRIND locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/fredix25/DSA-Grind.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DSA-Grind
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
