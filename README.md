## 🌐 About the Project

DSA-GRIND is an interactive platform designed to make Data Structures and Algorithms practice more structured, engaging, and consistent.

Whether you're starting from scratch or preparing for coding interviews, DSA-GRIND helps you organize your learning, track your progress, and stay consistent throughout your DSA journey.

## ✨ Features

- 📚 **Structured DSA Roadmap** — Explore topics from beginner to advanced levels.
- 🎯 **Curated Problems** — Practice coding problems organized by topic and difficulty.
- ✅ **Progress Tracking** — Mark problems as solved and monitor your progress.
- 🔥 **Daily Streaks** — Build consistency through daily practice.
- 📊 **Activity Heatmap** — Visualize your coding activity.
- 🔖 **Bookmarks** — Save important problems for revision.
- 📝 **Personal Notes** — Maintain notes for concepts and problem-solving approaches.
- 🔍 **Search & Filters** — Find problems quickly.
- 🎉 **Celebration Effects** — Get a little motivation when you solve problems.
- 💾 **Local Storage** — Save your progress directly in your browser.

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/fredix25/DSA-Grind.git
```

**2. Navigate to the project directory**

```bash
cd DSA-Grind
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Visit the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📦 Build

To create a production build:

```bash
npm run build
```

The generated production files will be available in the `dist` directory.

## 🌍 Deployment

This project is deployed using **GitHub Pages**.

To publish future updates:

```bash
npm run deploy
```
